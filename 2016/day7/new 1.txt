Before you leave, you are granted a map of the city (your puzzle input).

The map is a grid of arrows, where each arrow represents the direction of the street at that location.

For example:

>>>>vvv>vv
>^>>>>>>>v
>>^<>vvv>v
^^^>>vv>^v
^<<<v>vv>v
^<>^<>v>v<
>^^<<<<<vv
^^^<^v<<>v
^v<^<<vvvv
^<^<<<<<<<
You begin in the top-left corner of the map.

From each street, you may only drive in the direction indicated by the arrow.

The first street you are in (top-left) is marked >, this means you have to drive to the street on the right of it.

After following four right-pointing streets, you arrive at a street marked v, forcing you to continue downward instead.
Eventually, you'll arrive at a street you've already visited. At that point, you've entered a loop and will never reach any new streets.
Your task is to determine how many distinct streets you visit before visiting a street you already visited before.
For the example above, you visit 45 distinct streets before visiting a street you've already visited before.

The streets are designed in such a way that no arrow ever points towards the outside of the grid. (You truly can never leave)
How many distinct streets do you visit before revisiting a street?
Your answer was: 241

-= Part 2: Connections With The Mayor =-
To maximize customer satisfaction, the mayor of the city has made a deal with the company, you are allowed to change one singular street's direction to a different direction.
There is one restriction though, the street you change may not be on the edge of the map. (again, you truly can never leave)
Consider every possible valid change and determine which one lets you visit the largest number of distinct streets before revisiting a street.
For the example, the following changes improve the result:

Changing the street at row 2, column 4 from > to v results in 46 visited
Changing the street at row 2, column 8 from > to ^ or v results in 47 visited
Changing the street at row 6, column 2 from < to > results in 49 visited
Changing the street at row 7, column 2 from ^ to > also results in 49 visited
Every other valid change either leaves the result unchanged or even make the score worse.

The best possible result for the example is 49.

What is the maximum number of distinct streets you can visit if you're allowed to change the direction of exactly one non-edge street?

// 2. Circular Queue implementation for Point structs
typedef struct {
    Point data[QUEUE_CAPACITY];
    int head;
    int tail;
    int size;
} Queue;

void queue_init(Queue *q) {
    q->head = 0;
    q->tail = 0;
    q->size = 0;
}

bool enqueue(Queue *q, Point p) {
    if (q->size == QUEUE_CAPACITY)
        return false;
    q->data[q->tail] = p;
    q->tail = (q->tail + 1) % QUEUE_CAPACITY;
    q->size++;
    return true;
}

bool dequeue(Queue *q, Point *out_p) {
    if (q->size == 0)
        return false;
    *out_p = q->data[q->head];
    q->head = (q->head + 1) % QUEUE_CAPACITY;
    q->size--;
    return true;
}

                   bool visited[ROW_COUNT][COL_COUNT]) {
    return (r >= 0 && r < ROW_COUNT && c >= 0 && c < COL_COUNT &&
            grid[r][c] == 0 && !visited[r][c]);
